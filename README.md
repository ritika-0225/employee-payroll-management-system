# Employee Payroll Management System

A web-based Employee Payroll Management System developed using Spring Boot, MySQL, HTML, CSS, and JavaScript.

## 📌 Project Overview

This project was developed as a Final Year BCA Project to simplify attendance tracking and payroll-related processes through automation.

The system combines employee management, attendance tracking, GPS-based verification, and payroll management into a single platform.

Employees can securely log in, mark attendance using location-based check-in/check-out, and access their dashboard, while administrators can monitor employee records, attendance history, and payroll details.

---

## 🚀 Key Features

- Secure role-based login system (Admin & Employee)
- GPS-based attendance verification
- Real-time check-in & check-out tracking
- Employee records management
- Attendance history management
- Salary calculation module
- Admin dashboard for monitoring employees
- Centralized MySQL database integration

## ▶️ How to Run the Project

### Prerequisites
- Java JDK 17+
- MySQL
- Maven
- Eclipse / IntelliJ IDEA

### Steps

1. Clone the repository
2. Open the project in Eclipse or IntelliJ IDEA
3. Configure MySQL database in `application.properties`
4. Create the required database and tables
5. Run the Spring Boot application
6. Open browser and visit:

```text
http://localhost:8080
```
